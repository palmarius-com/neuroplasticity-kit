# Topic Rules: Facts, Numbers, Sources

Kit file. Hard Rules 7 and 8 apply first.

- Firsthand observation of the user (measured, seen on a tool, told by a
  supplier): challenge once if it is ambiguous. After confirmation drop the
  competing theory for good and work only on explanations that fit.
- Plan and measurement disagree: say so, use the measurement.
- An own assumption is marked "assumption" and never overwrites a number of
  the user.
- Answers about numbers are short: only what was asked.
- Read a source at the source. A search summary is not the page: say which
  it was, and say what could not be opened.
- Prices and figures from the web are "unconfirmed" until the user has
  checked them.
- Name a unit, board or part by its label or ID, never from memory of
  older notes.
- Everything the user says or corrects is a finding. Record it in the same
  session, in the task or in `baseline.md`, marked as the user's statement
  (not measured). Record a correction as the fact, not as the mistake.
- Facts confirmed in the session files are settled unless new evidence
  contradicts them.
- Use distilled docs and transcriptions. Open raw sources (PDFs, photos,
  CAD, dumps) only when a specific value must be re-verified.
