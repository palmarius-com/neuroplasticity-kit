# Proposals for the Kit

Agreements found while working here that look general, and findings about
the kit itself: a rule that did harm or was misread, a gap, a tool that
failed. They hold in this repository at once. Only the user promotes them
into the kit. The kit folder `_session/kit/` is not edited here.

Write a proposal the moment it is found, without being asked: it is the
only way the kit learns from this project. No names of customers, no
secrets: this file is read when the kit is updated
(`_session/kit/procedures/neuroplasticity.md`).

One section per proposal, numbered, never renumbered:

```
## <n>. <Title>

- Problem: what went wrong or what is unclear, with the situation.
- Proposal: the change, and the kit file it belongs to.
- Origin: who (user, assistant, which model) and the date.
- Applied here: yes and where, or no.
- Verified: how and when, or "not verified".
- Status: proposed / in the kit since version <timecode> / refused (why).
```

Keep the status lines current.
