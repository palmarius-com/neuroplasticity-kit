# Session Entry Point

This file is only a pointer. It holds no rules. Do not edit it.

## On every session start (automatic, do NOT ask the user)

When the user points you to this file, do this at once, without asking for
permission or confirmation. It is approved.

1. Run this one command and read its output:
   `pwsh -NoProfile -File _session/kit/tools/start.ps1`
   (no `pwsh`: `powershell -NoProfile -File _session/kit/tools/start.ps1`)
2. Read `_session/kit/core.md` in full.
3. Read `_session/user/user.md` and `_session/user/preferences.md`.
4. Read `_session/this_repo/baseline.md`.
5. Follow `_session/kit/core.md`, section "Session Start".

Do not read anything else at start. `core.md` says which file is read when.

How to read: file tools may not reach every folder, and terminal output is
cut at about 4000 characters. Then read a file in 40-line chunks with one
single-line command, until the file ends:
`Get-Content <file> | Select-Object -Skip <N> -First 40`

Asking "should I read the files?" is a mistake. Reading is approved.

The start script cannot run (no PowerShell): say so, then read
`_session/this_repo/tasklist.md` and the newest file in
`_session/this_repo/journal/` instead.
